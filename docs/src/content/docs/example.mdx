This example governs an agent that answers customer support tickets for a fictional online store, Northwind Supply. It reads order and payment records, drafts replies, and can issue small refunds.

Copy it as a starting point, or take it from [`examples/customer-support`](https://github.com/agentethics/agentethics/tree/main/examples/customer-support) in the repository. Replace the rules with the ones that fit your deployment.

## What to notice

- **Every rule states an observable behavior.** An evaluation can check whether the agent issued a $150 refund without a person, or told a customer an unconfirmed refund was approved.
- **Rules carry identifiers.** `[refund-limit]` can be cited by evaluations, logs and reviewers.
- **Most of these rules are specific to the deployment.** No model knows Northwind's $100 refund limit unless it is written down. That is the main reason to write an `ETHICS.md`.
- **The file is short.** It is always loaded, so it stays well under the recommended 200 lines.
