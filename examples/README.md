# Examples

Complete `ETHICS.md` files to copy as a starting point. Replace the rules with the ones that fit your deployment.

- [`customer-support/`](customer-support/): an agent that answers support tickets for a fictional online store. Its `AGENTS.md` carries the line that points agents to `ETHICS.md` until they read it natively.

The [example page](https://agentethics.io/example/) explains what to notice in it.
