# Agent Ethics Documentation

This directory contains the source for the Agent Ethics [documentation site](https://agentethics.io/), built with [Mintlify](https://mintlify.com).

## Development

Run the following command in this directory, where `docs.json` is located:

```bash
npx mint dev
```

View the local preview at `http://localhost:3000`.

## Publishing changes

Changes are deployed automatically after pushing to the default branch.
